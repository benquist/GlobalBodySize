# FRED Provider

Source: Fine Root Ecology Database (FRED) candidate manifest — FRED-identified Dryad deposits not yet in main DataDryad compiled output.
Publication: See FRED at https://roots.ornl.gov/
Ingest script: providers/fred/scripts/download_and_compile_fred_traits.R
Output: output/providers/fred/compiled_trait_observations.csv
Note: FRED candidates are Dryad-hosted. Files >100MB, genomics files, simulation outputs, and climate logger files are excluded.
