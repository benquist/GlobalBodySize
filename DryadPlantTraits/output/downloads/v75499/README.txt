*******************************************************************************


The following files are included:

1)	"functional_traits.csv" 
The file contains individual-wise functional trait measurments. Missing values are indicated through empty fields. LA, SLA, LDMC SPS and SPI represent individual mean values and now raw data. See "Methods" chapter of publication 	for further details. Please note that outliers are already excluded.

2)	"environmental_parameters.csv"
The file contains environmental measurments based on vegetation records. Missing values are indicated through empty fields. Ta and Pa were only once determined per location. See "Methods" chapter of publication for further details.


3)	"environmental_parameters_soil_depth_LAI.csv"
The file contains environmental measurments of soil depth and LAI based on vegetation records. Missing values are indicated through empty fields. Ta and Pa were only once determined per location. See "Methods" chapter of publication for further details.


4)	"population_genetics.csv"
This file is prepared as a codominant matrix for GenAlEx including nine microsatellite loci. Values represent allelic fragment sizes. Missing values are indicated through empty fields. See "Methods" chapter of publication for 	further details.

5)	"pop_means_CV_functional_traits.csv"
The file contains population-wise functional trait diversity. We approximated Fv/Fm and PI values of location Riezlern (KW). See "Methods" chapter of publication for further details. These data are also included in Extended Data chapter of publication.

6)	"pop_means_environmental_factors.csv"
The file contains population-wise environmental factors. See "Methods" chapter of publication for further details. These data are also included in Extended Data chapter of publication.

7)	"pop_means_CV_environmental_factors.csv"
The file contains population-wise variability of environmental factors. See "Methods" chapter of publication for further details. These data are also included in Extended Data chapter of publication.

8)	"pop_means_genetic_diversity_indices.csv"
The file contains population-wise genetic diversity indices. See "Methods" chapter of publication for further details. These data are also included in Extended Data chapter of publication.

9)	"pop_means_FD_HD_GD.csv"
The file contains population-wise mean of functional diversity (FD), habitat heterogeneity (HD) and genetic diversity (GD). See "Methods" chapter of publication for further details. These data are also included in Extended Data chapter of publication.
