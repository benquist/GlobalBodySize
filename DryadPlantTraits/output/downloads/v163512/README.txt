DESCRIPTIONS OF COLUMN HEADERS			
	Column	Description	Units
	Latin.name	Species name with subspecies and/or variety	no units
	Species	Species name with out subspecies and/or variety	no units
	SPPcode	six-letter species code: first three letters of genus followed by first three letters of species	no units
	Category	USDA PLANTS Database: type of plant: gymnosperm, monocot, dicot	no units
	Duration	USDA PLANTS Database: how long the plant lives: Annual, Biennial, Perennial	no units
	Growth_Habit	USDA PLANTS Database: growth from of plant: herb, forb, graminoid, subshrub, shrub, tree, vine, or a combination of these	no units
	Family	plant family	no units
	Soil	Soil type on which traits were collected: n=non-serpentine, s = serpentine	no units
	Height.cm	Plant height measured to the highest photosynthetically active tissue	cm
	SLA	specific leaf area = fresh leaf area/dry leaf mass	cm2/g
	LWC	leaf water content = fresh leaf mass/dry leaf mass	g/g
	CN	Leaf carbon to nitrogen ratio	no units
	wood_density	wood density = dry mass of branch/fresh volume of branch	g/mL
	Seed mass	seed mass obtained from KEW Royal Botanical Gardens Seed Information Database: http://data.kew.org/sid/	g/100 seeds
	DispersalSyndrome	Dispersal syndromes, determined by searching the literature, syndromes are not listed in any order	no units
	Wind	Binary value for if a species has this dispersal syndrome: 1= yes, 0 = no	no units
	Unassisted	Binary value for if a species has this dispersal syndrome: 1= yes, 0 = no	no units
	Adhesive	Binary value for if a species has this dispersal syndrome: 1= yes, 0 = no	no units
	Animal	Binary value for if a species has this dispersal syndrome: 1= yes, 0 = no	no units
	Ant	Binary value for if a species has this dispersal syndrome: 1= yes, 0 = no	no units
	Water	Binary value for if a species has this dispersal syndrome: 1= yes, 0 = no	no units
	Tumbling	Binary value for if a species has this dispersal syndrome: 1= yes, 0 = no	no units
	Bird	Binary value for if a species has this dispersal syndrome: 1= yes, 0 = no	no units
	Mammal	Binary value for if a species has this dispersal syndrome: 1= yes, 0 = no	no units
	Ballistic	Binary value for if a species has this dispersal syndrome: 1= yes, 0 = no	no units
