GENERAL INFORMATION
  Data from: "Assessment of biogeographic variation in traits of Lewis flax (Linum lewisii) for use in restoration and agriculture"

  Code for analysis of all data is available at: https://github.com/peterinnes/Lile_common_garden



DESCRIPTION OF FILES
I. Sample collection data:
  File 1 Name: LILE_seed_collection_spreadsheet.csv
  File 1 Description: Accession information (e.g. names, geographic origin).

II. Ephraim garden data:
  File 2 Name: cleaned_LILE_yield_data_2013_fruit_fill.csv
  File 2 Description: Variables include number of good seeds, bad seeds, total seeds, across blocks/rows/plots. Used to calculate fruit (capsule) fill. Note: the variable 'trt' refers to whether plants were harvested for other phenotypic measurements (e.g. those in File 4) or not: 'trt B' were harvested and further analyzed, 'trt A' were not harvested.

  File 3 Name: cleaned_LILE_yield_data_2013_seed_wt.csv
  File 3 Description: Variables include seed mass per 50 seeds, across blocks/rows/plots. 'rep' refers to technical replicate. All measurements are of 50 seeds unless otherwise noted.

  File 4 Name: cleaned_LILE_yield_data_2013_stem_and_fruit.csv
  File 4 Description: Variables include number of stems per plant, capsules per stem, buds/flowers per stem, forks per stem, capsule diameter, stem diameter, across blocks/rows/plots.

  File 5 Name: StanHtCrownRustJune3_4_13.csv
  File 5 Description: Variables include observational rust measurements on both June 4th and June 17th (only June 17th was analyzed), as well as plant Height, across blocks.

  File 6 Name: Brant_Flax_GC_Complete.csv
  File 6 Description: Oil composition data across blocks ('BL'). Variables for percentages of each component fatty acid (FA) are included; FAs in trace amounts (Palmitoleic, Arachidic, Gondoic) were not analyzed. Percentages were ultimately converted to g FA per kg total oil for publication.

  File 7 Name: perennial_flax_paperNMR.csv contains oil content data
  File 7 Description: Oil content data. 'Adj_Oil' is the only variable analyzed here and is oil content, adjusted by sample mass.

III. Millville garden data:
  File 8 Name: TomJ_2013_stems_caps_ht_diam_surv_ANALYZE_THIS.csv
  File 8 Description: Variables include total stems per plot, stems per sub-sample, capsules per sub-sample, estimated total capsules. 'av_ht' and 'av_diam' and survival are analyzed in separate files.

  File 9 Name: TomJ_flax_avg_ht_dia_2013_RAW_DATA.csv
  File 9 Description: Variables include plant height and diameter for individual plants across blocks ('Rep') and Plots.

  File 10 Name: TomJ_BiomassFlax2013_14_15_ANALYZE_THIS.csv
  File 10 Description: Variables include 2013 and 2014 Biomass ('ttl_weight') across Blocks ('Rep') and Plots.

  File 11 Name: TomJ_linum_lewisii_survivorship_flwr_full_(ANALYZED_IN_FILE).csv
  File 11 Description: Variables include number of surviving plants at different dates, across blocks ('Rep') and plots.

IV. Miscellaneous
File 12 Name: StanVsTomAccessions.csv
  File 12 Description: Key for converting accession 'source' numbers used in Ehpraim datasheets to accesssion 'Entry' numbers used in Millville data sheets.

Notes on experimental design variables in above files:
'source' and 'Entry' refer to accession i.e. population and correspond to data from Ephraim and Millville, respectively. A key for source vs Entry comparison is provided in File 12. In the Ehpraim seed oil datasheets, 'BL' is a synonym for 'block.' In the Millville data, 'Rep' refers to Block.
